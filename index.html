🎵 YT Music Web Mixer

⚠️ Lecture DJ indisponible. Pour préserver le mixage, basculer les deux decks en YT IFrame ?

⚙️ Paramètres

La clé n'est jamais embarquée dans le code ni transmise hors des appels à l'API YouTube officielle. Créez-en une sur Google Cloud Console (API YouTube Data API v3 activée). Quota gratuit : 10 000 unités/jour (≈ 100 recherches).

🔊 Mode de lecture

DJ (Audio / DSP) — vrai mixage audio (crossfade, EQ, filtres, analyse) via Web Audio API. Audio uniquement, pas de vidéo YouTube.
YT IFrame (YouTube) — lecteur vidéo officiel, crossfade par volume uniquement (pas de DSP).
Auto — DJ si les instances sont disponibles, sinon YT IFrame (résolu au démarrage).

Le bouton d'en-tête permute DJ ↔ YT IFrame (les deux decks ensemble). « Auto » n'est atteignable que depuis ce menu.

🎚️ Crossfade progressif

Atteint la valeur cible du crossfade par paliers au lieu d'être instantané. Mettre le palier à 100 % ou l'intervalle à 0 ms pour un comportement instantané.
